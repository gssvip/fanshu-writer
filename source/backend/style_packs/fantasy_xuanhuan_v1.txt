【文风对齐 SkillPack · 玄幻/仙侠 V1（贺平生·五行灵根 + 黎渊·苍天授箓锻兵铺 黄金范本）】
定位：内置写在系统 prompt 第 3 位（core_iron → ONE 主钩子之后，bible_ctx 之前），模型先读这套正面范例再写，远胜 50 条禁令。

------------------------------------------------------------
Part A：10 条必须照做的写作铁则（从两本范本中直接提炼，不是口号）
------------------------------------------------------------

铁则 1【ONE 主钩子贯穿本章】：本章只有一个核心对象/核心任务贯穿到底（例：聚宝盆→翻倍→翻倍→翻倍→每一场都绕回聚宝盆；苍天授箓→准备→买五牲→布置仪式→每一场都绕回"仪式要做成"）。**严禁出现"隔壁矿友讨水"这种删了不影响主钩子后续的独立路人支线——哪怕只有 200 字也不行。**

铁则 2【对话=身份说话，不是作者问答】：
  - 反派/上位者勒索人，绝对不说"把 X 给我不然我打你"，要说（参考张老大勒索丹药）：①先翻歪理「小贺啊…我打你其实是救你啊！」 ②翻话「救命之恩，你不能不报吧？」 ③动作「目光往怀里盯」 ④提容器不提物品「我要那个带瓶子的」。
  - 身份尊贵者被打脸/错怪，绝对不说"对不起我错怪你了"，要（参考粉衣女甩锅）：心里骂自己"我怪错人了" → 嘴里立刻甩锅转题「你是挑水的，水质变了你应该第一时间告诉我，此事你难辞其咎」。
  - 任何人紧张/愤怒/隐瞒，越不说完整漂亮话。"怕不怕？" / "……" / "问你话呢！" / "我怕你不敢来。" —— 这才是正常人的说话方式。

铁则 3【动作链=小目标链=闭环】：每 200-300 字必须有一个"目标→决策→决策被验证"的小三段闭环。**绝对不允许"挖→藏→黑狗来→鞭打→包扎→震片"这种不知道下一步要做什么的流水账。**
  - 参考贺平生（3 个连续闭环）：
    目标 A「丹药放哪？」→ 决策「装陶盆盖木板塞床底」
    目标 B「金米搬家带不走？」→ 决策「全倒粪口（怕搜身）」
    目标 C「郝师兄搜陶盆？」→ 验证「还好早前倒了金米」= B 决策正确
  - 读者读起来就像在看一个人一步步解决问题，不是看动作列表。

铁则 4【提示语 ≥60% 放对白后或对白中（句首≤40%），跟禁令3口径完全一致】：
  - ✗ 错误：姜雪攥紧衣角说："你在名单上。"（句首提示语=超过 40% = AI 机械病）
  - ✓ 正确："你在名单上。"姜雪攥紧衣角。布料在指缝间发出细碎声响。（提示语放对白后，再加一个小动作/小触感收。60% 以上对白都应该这么写。）

铁则 5【人物群像场景=递进比较链长句→1-4 字动作短句收尾】：
  - ✓ 参考黎渊锻兵铺学徒对比（4 层递进）：
    比起中院小鸡崽子似的学徒们，前院的学徒一个个壮实的好似小牛犊子。
    这一个多月里，他的身体也养起来不少，可比起这些牛犊子似的前院学徒，肉眼可见的差距颇大。
    可见，同为学徒，前院和中院的学徒，除了铺子内的待遇、根骨的差距之外，家境也有差距。
    不过，这些'小牛犊子'比起他们身后那人，可就又是小巫见大巫了。
    「这人好壮！」 / 黎渊眼皮一跳。 ← 4 字动作短句收尾。
  - ✗ 错误：4 段均匀等长描述（一段写中院/一段写前院/一段写家境/一段写壮汉），每段结尾都总结。

铁则 6【感官细节三叠（温度/气味/触感/声音选 2-3 叠，不用比喻词）】：
  - ✗ 错误：他把残片藏进腰腹，忍痛咬牙继续装作若无其事。（一句带过，空）
  - ✓ 正确：残片棱角咬进掌心，他没松手，把湿泥按上去，冷意混着血味从指缝里渗出来。（动作=藏→咬进→按泥→渗，感官=棱角触感+湿泥凉+血味）

铁则 7【修正感句式，拒绝机械直给】：
  - ✗ 错误：他脊梁骨发凉，很痛，心里发颤。（3 句并列机械）
  - ✓ 正确：不是痛。是一种凉，顺着脊梁往上爬，像谁把冰碴子一根根塞进骨缝里。（先否定→再修正→再说清楚——像人真实的感知过程）

铁则 8【每 3 句对白必须插 1 句 POV 的小动作或小吐槽】：
  不允许 A→B→A→B 机械轮换两人对话。参考林星发达那段：「我们要发达啦！」/ 林星愣了下，"发达？" / "你是富婆吗？" / "……唐虎今晚堵你，我们一闷棍撂倒他就跑路。"（中间插了"林星愣了下"的小动作和"你是富婆吗？"的答非所问吐槽）

铁则 9【冲突场景=爆发式密集短段，但整章段数必须遵守禁令5上限】：
  打架/紧张/对峙的高潮段（≤整章20%篇幅）内，80%-90% 段落可以是一个动作/一句对白各成一段，这是真人网文的爆发式节奏，不是"短段堆砌毛病"；⚠️ 但其余叙述段必须按真人段长均值 23.7字/段写，**全章段数超过禁令5上限=漫画分镜脚本化→主动合并同场景段**；真正该防的是长段臃肿（≥100字一段连续写景/写背景说明，整章占比>3%就是病），不是冲突高潮段的密集短段。

铁则 10【结尾只留 1 个钩子，而且必须和本章冲突链的最后一环关联】：
  - ✗ 错误（《矿道》病）：结尾一次性铺 3 个未暗示新坑（古字 / 炉子铛铛 / 黑煞风撞门），每个都没下文。
  - ✓ 正确：本章冲突链最后一环是"黑狗踩姜离手→残片冒黑烟" → 结尾就写一个钩子「黑煞风撞过铁门。姜离掌心的黑烟顺着门缝飘了出去。」= 既延续了冒黑烟的伏笔，又留悬念，而且只留 1 个。

------------------------------------------------------------
Part B：玄幻专属「人物/身份/对白」对照清单（贺平生+黎渊里反复出现，直接照着写就对）
------------------------------------------------------------

 1. 小人物对话里必须带"身份焦虑/翻话逻辑"：小人物被大人物欺负→小人物嘴上绝对不敢硬怼但心里骂→但会找歪理翻回来（参考贺平生把金米倒粪坑的"暗报复"，不写在嘴上写在动作上）。
 2. 大人物说话必须"下命令式半句话+不解释"：（参考张老大「我要那个带瓶子的」——不解释为什么要、不解释是啥，就是要）。
 3. 学武/修炼场景必须写"身体的疼痛+吃的对比"（参考黎渊白猿桩=腿疼到下不来床/前院学徒吃的比中院好一倍），不写"境界+1+1+1"这种流水账。
 4. 捡漏/奇遇前必须铺垫 1-2 章的"穷困/被欺负/差一步死"（参考贺平生被暴打→几乎要死了→青衣女赔丹药→丹药入陶盆翻倍），不然爽点不成立。
 5. 所有出场人物的瑕疵必须落地：（不是"性格有小毛病"这种空话）贺平生"吝啬但对自己好的人豁得出去"、黎渊"会算账/会省钱/买五牲要讲价"、张老大"克扣半份灵米"、粉衣女"甩锅不认账"——每一个人的坏/好/纠结都必须落在一件具体的小事上。
 6. 伏笔晒宝必须 3 章内回收：贺平生章 2 姑奶奶问水质变差→章 7 揭秘"之前陶盆在潭底稀释水所以甜/被取走就无味"；绝对不能埋一个"青铜残片上古字"10 章还不揭。
