# 正文写作质检清单

> 正文写作完成后的质检清单，确保质量达标。

## 快速检查（5分钟）

### 1. 禁用词扫描
- [ ] 无一级禁用词（仿佛、缓缓、眼中闪过、心中一动...）
- [ ] 无二级禁用句式（"他终于明白..."、"一切...都..."）

### 2. 风格检查
- [ ] 情绪用动作展示，而非直接告诉
- [ ] 短句为主，长短交错
- [ ] 口语化表达，无书面腔

### 3. 连续性检查
- [ ] 金钱、物品、时间、位置无矛盾
- [ ] 角色口吻与状态机一致
- [ ] 无OOC行为

### 4. 结尾检查
- [ ] 硬截断（动作/对话/景物）
- [ ] 无总结、无预告、无说教

### 5. AI味检查
- [ ] 无总结升华句
- [ ] 无说教句
- [ ] 无预告句
- [ ] 无过度解释

## 深度检查（15分钟）

### 6. 衔接检查
- [ ] 句间过渡自然
- [ ] 无拼接痕迹
- [ ] 无重复表达

### 7. 节奏检查
- [ ] 情绪有起伏
- [ ] 张弛有度
- [ ] 高潮位置恰当

### 8. 对话检查
- [ ] 每句推动信息或关系
- [ ] 有角色指纹（换角色说不成立）
- [ ] 动作标签 > "说/道"

## 评分

| 维度 | 通过标准 |
|------|---------|
| 无禁用词 | 0处 |
| 风格一致性 | 符合个人风格 |
| 连续性 | 无矛盾 |
| 衔接 | 自然流畅 |
| 节奏 | 有起伏 |
| AI味 | 0处 |

**全部通过 → 进入后置流程**
**有未通过项 → 修订后复检**
