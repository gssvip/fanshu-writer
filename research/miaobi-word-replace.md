# 词汇替换参考指南

> 正文草稿生成后，为每个段落提供同类型内高权重替代选项。

## 输入

- 正文草稿
- 语句素材库（按类型隔离权重）

## 处理流程

### 逐段识别

1. 扫描段落中的关键词汇和表达
2. 按功能分类（写人/写景/写情/写动作/写神态/写心理/写对话/写氛围/五感/修辞）
3. 标记可替换项

### 检索替代

1. 在语句素材库的同类型文件中检索
2. 按权重分数排序（同类型内）
3. 过滤近期已用项（本章/本卷）

### 输出格式

```markdown
## 第X段替换参考

**原文**：
> [段落原文]

**可替换项**：

| 原文表达 | 替代选项1 | 替代选项2 | 替代选项3 |
|---------|----------|----------|----------|
| "XXX" | "YYY"(+15) | "ZZZ"(+12) | "AAA"(+8) |

**类型**：01_写人/外貌描写
**推荐**："YYY"
```

## 排序规则（同类型内）

```
最终分数 = selected_count * 2 + reuse_count * 3 + like_score - recent_penalty

recent_penalty:
  - 本章已用：-1
  - 本卷已用：-0.5
  - 长期未用(>10章)：+1

排序步骤：
1. 过滤禁用项（ban=true）
2. 按最终分数降序
3. 同分按使用频率排序
4. 每类至少提供3个不同分数段选项
```

## 用户操作

1. 查看每段替换参考
2. 选择替代选项或保留原文
3. 手动修改正文
4. 确认最终版本

## 权重更新（用户确认后）

| 操作 | 权重变化 | 作用范围 |
|------|---------|---------|
| 选中替代 | +10 | 同类型内 |
| 弃用原文 | -10 | 同类型内 |
| 本次使用 | +2 | 同类型内 |

## 输出产物

- 词汇替换参考：内嵌在草稿中
- 更新后的语句素材库：`{project_root}/拆文分析/语句素材库/`
