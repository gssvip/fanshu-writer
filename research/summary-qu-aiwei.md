### 2.1 oh-story-claudecode（worldwonderer，5.9k star）— 网文全流程skill包

`skills/story-deslop/` 去AI味自检+改写，含 `anti-ai-writing.md`（36KB完整指南）+ `banned-words.md`（禁用词句式表）。详见 `ohstory-anti-ai.md` / `ohstory-banned-words.md`。

**最毒禁用句式（出现即修）**：
| 毒级 | 句式 | 修法 |
|------|------|------|
| ★★★★★ | "不是A，（而）是B" | 直接写B或更自然的表达 |
| ★★★★ | "，带着……"万能状语 | 删状语留主句，或换具体动作 |
| ★★★★ | 无情绪声线"声音不大，却带着…" | 直接写台词内容/声音特征/动作 |
| ★★★★ | "他/她知道……" | 用行为展示认知 |
| ★★★ | "仿佛/犹如/宛若……一般" | 删掉或白描 |
| ★★★ | "眼中闪过一丝…" / "嘴角勾起一抹…" | 他垂下眼 / 他嘴角一扯 |
| ★★★ | "心中涌起一股…" / "心头一震" | 用身体反应 |
| ★★★ | 抽象命运收束"命运终于露出獠牙" | 回到角色当下可见的动作/对话/物理后果 |
| ★★ | 章末预告"他不知道的是……" | 删掉 |

**核心规则**：
- 段落密度：一段只承载一个动作/一个信息变化；逗号串太长按动作拆开；连续短段碎成提纲时合并
- 动作+对话+情绪反应三要素循环，不单写心理超过2段
- 句长：叙述默认逗号长句（逗号间8-12字，整句20-30字）；短句是偶尔的重拍工具不是默认（爆款语料校准：七猫125本长篇，逗号长句占叙述句74-80%）
- 情绪外化：不写"他很紧张"→"手心全是汗，筷子差点掉了"（低强度过场情绪可一笔直写）
- 章末总结体禁止：总结性感悟/升华式感叹/哲理式收尾/伏笔式预告 → 章尾用动作、对话或悬念收束
- 叠加式描写（同一动作掰开写三遍）→ 发生、感知、反应揉进同一段连续正文
- 引号只承载真实引用，不给普通名词加"引号强调"

### 2.7 short-story-crafter（腾讯SkillHub，@user_7ca3a4d6/short-story-crafter v1.0.0，作者天昊）— 番茄短篇爽文

**AI味三维体检**：
- 特征1"逻辑闭环"强迫症：迫不及待解释每件事的前因后果（因为/所以/鉴于/由于/为了/试图）→ 删逻辑连接词，让冲突直接呈现
- 特征2"情绪感知"屏蔽罩：只告诉读者人物心情（愤怒地/悲伤地/百感交集）→ 用生理反应替代情绪形容词
- 特征3"视觉密度"超载：一段话长达5-7行 → 超过3行的段落必须拆分

**三刀流去AI味**：
- **第一刀：斩断逻辑链** — 搜索并删除因果关系词（因为/所以/由于/因此）、目的意图词（为了/试图/企图/想要）、解释说明词（实际上/事实上/换句话说）
- **第二刀：粉碎形容词** — 铁律："生气"是不值钱的，"砸东西"才值钱。愤怒（重）=手背青筋暴起/抄起烟灰缸砸过去/掀翻桌子；恐惧（重）=腿软跪下/牙齿打颤/裤裆湿了一片；悲伤（重）=捶胸顿足/哭到干呕/一夜白头；震惊（重）=手里的东西掉在地上/瞳孔地震
- **第三刀：改掉AI式结尾** — 禁止与主线无关的环境描写、多余的主角心理独白、无意义的配角台词、为留钩而留钩的反转；要求钩子紧扣爽点方向、动作或对话结尾、恶有恶报的因果闭环

**四句顺口溜**：浮夸修饰先砍掉；比喻套路连根刨；多余尾巴快切掉；原意根基不可摇。

**词汇表补充**（ssc-ai-flavor-words.md）：复合情绪词（百感交集/五味杂陈/心潮澎湃/忐忑不安/怅然若失/喜出望外/怒不可遏/悲痛欲绝）必须替换；抽象概括词（内心深处/灵魂深处/某种难以名状的感觉/一种莫名的情绪）避免使用；心理描写句式（"她感到…"/"一种…的感觉涌上心头"/"她不禁想到…"）全部改写。

## 三、知乎/公众号/抖音/头条 网文去AI味技巧

### 3.1 AI味的本质（人人都是产品经理，公众号长文）

> **AI味的本质是英语式表达带来的译制感**——主流大模型语料以英文为主，输出的是"英译中"句式。
典型英译中句式：`……又……`（滑稽又可笑）/`目光像淬了冰的刀，狠狠扎在心上`/`每一个字都像一记重锤`/`他，张三，龙族太子……`/`眼神里有XX，但更多的是XX`。
解法：光禁用词汇不够，要从**汉语原生表达**入手，把网文大神的遣词造句融入提示词（人物出场白描、动作流推进等）。

### 3.2 加、删、拆、问四步公式（头条，半年实测）

1. **加**：为每个抽象概括句加真实可感知的具体例子（"提升了工作效率"→"原来40分钟的报表现在15分钟拉完"），每200字至少1个
2. **删**：删掉"专业、正式、严谨"类提示词，换成"用跟朋友吃饭聊天的语气写"
3. **拆**：拆长句为短句，控制节奏
4. **问**：让AI以读者身份自查："请以读者的身份阅读以下修改后的文字，找出至少两处读起来仍然别扭、不像真人会说的地方，并按日常口语习惯重新改写"

### 3.3 老编辑三步改造法（公众号）

1. **打破句式对称**："他勤奋工作，努力学习，积极进取"→"他白天上班，晚上刷课，周末还在赶项目"
2. **书面语换口语**："该方法效果显著"→"用完之后我直接惊了，转化率飙到12%"
3. **让读者自己算账**：别写"她终于明白了"，把行为和对话摆出来；信息给八成，剩两成是阅读动力

加真实细节是"最管用的一招"：AI写"她感到非常愤怒"→"她当时就火了，心里一万头神兽奔腾过"。**AI没有活过**——它写的痛苦是语料库的平均值，只有信息没有经历。

### 3.4 全套洗AI痕迹指令（头条，网文专用三层洗稿）

详见 `xi-ai-henji-zhiling.md`（快速简易版/强效通用版/终极洗稿指令全文）。核心逻辑五条：
1. 删AI模板词（喉结滚动、瞳孔微缩、心头一震、周身散发、无形压力…）
2. 打散规整句式（5字+20字+35字随机穿插，连续三句同长度绝不允许）
3. 加真人碎片化感官（搓指尖、走神、视线飘开、脚步顿半秒）
4. 打破完美逻辑（一半逻辑靠场景带出，不用明说关联词）
5. 植入细微情绪瑕疵（犹豫、模糊、没想明白的细碎思绪）

### 3.5 玉芬AI三步法（SegmentFault）

1. 负面词拦截表（系统提示词加入违禁词约束：空气中弥漫着/他的眼中闪过一丝/嘴角微微上扬/不得不说/仿佛在诉说着；连续"的"不超3个；情绪禁抽象词，必须心跳加快/瞳孔收缩/指甲掐入掌心）
2. 多模型微调链路：DeepSeek-R1出动作骨架 → Claude 3.5 Sonnet重写注入中式心理描写去翻译腔
3. 参数调节：Temperature 0.75-0.85 / Frequency Penalty 0.4-0.6 / Top P 0.85-0.90
人工润色最有效方法：**删掉三分之一修饰性形容词，被动改主动**（"他的肩膀被雨水无情地打湿了"→"雨水砸透了他的肩膀"）

### 3.6 通用去AI味万能提示词（头条，复制即用）

```
你是我的写作助手。请严格按以下规则写作：
1. 禁用词（绝对不要用）：综上所述、值得注意的是、不难发现、众所周知、总而言之、
   除此之外、值得一提的是、随着……的发展、在……的背景下、赋能、抓手、闭环、
   颗粒度、底层逻辑、落地、堪称、无疑
2. 文风：短句为主，口语化，像跟朋友聊天；不用排比句；不用"不仅……更是……"这类句式
3. 结构：第一句直接说事，不要铺垫；结尾写完就停，不要总结、不要客套
4. 内容：多举具体例子和数字，少说空话
5. 允许：可以有立场，可以口语化，可以用反问
```
核心规律：**让AI写之前，先把"不许写什么"说清楚，AI味去掉八成。**

### 3.7 其他实用技巧汇总

- **10个去AI味提示词模板**（CSDN）：聊天人设设定（"想象你正在跟[具体身份]聊天，用TA的语气，加点口头禅"）、场景画面感、长句变短、向读者提问、加个人经历、生活比喻、吐槽玩笑、小故事、口语化过渡（"哎对了""你猜怎么着"）、结尾互动
- **朗读自查法**：投稿前把文章读出来，读到突然变正经、像背课文的那段就是AI味重灾区
- **AI高频数字陷阱**：DeepSeek爱加莫名其妙的举例数字（"十几张人脸形状的印子"），规避指令：让AI不要加数字
- **好句式判断**：人类写作"指纹"=个人经历留下的语气习惯+情绪波动造成的句式变化+特定读者带来的表达调整；AI给不出这些维度时只会输出标准化的"平均值"

## 四、共性规律总结（跨三大来源）

1. **禁用词是基础盘**：仿佛/不禁/微微/缓缓/眼中闪过/嘴角勾起/心头一震/喉结滚动 几乎所有来源都禁
2. **句式比词汇更毒**："不是A而是B"是被点名最多的硬伤（qiaomu ★★★★★、oh-story ★★★★★）
3. **展示不告知**：情绪全部外化为动作/生理反应/物件细节
4. **节奏要乱**：AI味=均匀，人味=长短句无序交错+段落长短不一+偶尔跳跃
5. **删总结升华**：章末感悟、哲理收尾、伏笔预告、slogan式结尾全部禁
6. **提示词写法**：先列"不许写什么"（具体到词），再给身份+任务+样本；模糊指令="写得自然些"等于没说
7. **没有万能指令**：一键洗掉AI痕迹不存在，最后都要人工精修（多来源共识）
