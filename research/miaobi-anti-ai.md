# 反AI写作风格指南

> 用于正文写作时的风格约束，确保正文有"人味"。

## 核心规则

### 规则1：感官化、动作化写作

减少使用形容词，正常只需使用一个形容词。描写需要体现电影般的画面感、动作感，加入感官化和动作化的描写。

## 禁用词表

### 一级禁用（出现即替换）

| 类别 | 词汇 |
|------|------|
| 情态 | 仿佛、好像、犹如、一丝、一抹、些许、隐约 |
| 动作 | 深吸一口气、缓缓、不禁、微微、轻轻、淡淡 |
| 表情 | 眼中闪过、嘴角勾起、眉头微皱、瞳孔微缩 |
| 心理 | 心中一动、心头一震、心中暗道、不由得 |
| 判断 | 不容置疑、显而易见、毫无疑问 |
| 过渡 | 突然、瞬间、不由自主、情不自禁 |

### 二级禁用（高频出现时替换）

- "他/她终于明白..."
- "此刻，他/她..."
- "一切...都..."
- 连续3句以上相同结构的排比

### AI套路表达（建议删除或替换）

- 总结升华句："这一刻，他成长了"
- 说教句："他明白了，真正的力量不是..."
- 预告句："他不知道，更大的危机正在逼近"
- 过度解释：直接解释笑话含义、解释伏笔含义
- 抽象情绪词："他感到非常愤怒"、"她很伤心"

### 替换策略

| 原文 | 替换为 |
|------|--------|
| 抽象情绪词 | 具体动作 |
| "感到XX" | 外化表现 |
| 形容词堆砌 | 白描手法 |
| 总结升华句 | 直接删除 |
| AI套路表达 | 动作/对话/景物 |

## Show Don't Tell

| Tell | Show |
|------|------|
| 他很紧张 | 他攥紧了手里的纸杯，水洒出来一些 |
| 这间酒吧很吵 | 酒保凑到他耳边喊了两次他才听见 |
| 两人关系很差 | 他把烟掐灭在她刚泡的茶杯里 |

## 结尾铁律：硬截断

禁止：总结性感悟、升华式感叹、哲理式收尾、伏笔式预告

必须：动作/对话/景物截断，让情节本身制造余韵。

## AI味检测维度

| 维度 | 检测内容 | 标记颜色 | 处理方式 |
|------|---------|---------|---------|
| 一级禁用词 | 仿佛、缓缓、不禁等 | 🔴红色 | 必须替换 |
| 二级禁用句式 | "他终于明白"等 | 🟡黄色 | 建议替换 |
| AI套路表达 | 总结升华、说教、预告 | 🟠橙色 | 建议删除 |
| 抽象情绪词 | "他感到"、"他很" | 🔵蓝色 | 建议改写为动作 |

## 连续性追踪

正文写作前必查7个变量：金钱、物品、时间、位置、已知信息、能力状态、人际关系
